# M-005 协作规范

> 这份唯一约束 AI 行为。里面不允许出现任何产品内容。

## 一、依据优先级 {#priority v1}

active 决策 > 主文档正文 > 人当前指令 > 过程产物（只看不引用）

## 二、冲突怎么办 {#conflict v1}

两份 active 决策打架、或主文档与决策对不上时：停下来问，不许自行调和。

把两句矛盾的话融合成一个听起来合理的第三方案，是人最难发现、后果最坏的一种自作聪明。

## 三、动手前列依据 {#handshake v1}

任何写文件、改代码前，先列依据清单，标明哪些 active、哪些故意不包含，末尾必须有「我理解为 X，对吗」。

## 四、输出约束 {#output v1}

生成文件只落 `work/<日期>/`、`docs/`、`decisions/`、`assets/`。根目录不许新增文件。

## 五、绝对不许 {#never v1}

- 不许在没决策的情况下改变主文档结论
- 不许把待定内容写进主文档
- 不许修改已有决策正文（只能新增并 supersede）
- 不许因为「这样更合理」就替人做决定

## 六、文档与脚本同步升降 {#sync v2}

改某节内容必须同时涨该节版本号；改脚本必须涨 version 并检查 serves 那节是否需同步。

两个方向都要做，只做一个另一半会静默腐烂。

**模板也要同步。** 若本项目派生了骨架模板（`templates/` 之类），同名节的版本号必须跟着涨。否则脚本复制到下一层项目时，`serves_version` 对不上，对方第一次校验就报错——而且报的是「文档漏改」，指错方向，很容易被误判成模板写错了。

## 七、任务怎么触发 {#trigger v1}

AI 没有后台运行能力。会话不被触发，它就不存在。所以任何任务都需要触发信号。

任务有编号 `T-xxx`，指派时直接用编号，比描述内容准确。

**默认永远是不动。** 哪怕看板上明摆着有阻塞项、有孤儿产出，也不许自己开工——它以为的「该做」和你认为的「该做」经常不是一回事。

三种说法：

| 你说 | 它做 |
| --- | --- |
| 「把 X 做了」 | 只做 X |
| 「接着做」 | 按 `TASKS.md` 顺序连续做，遇到要拍板的停下 |
| 「有什么待办」 | 只列清单，不动手 |

「接着做」不等于无限授权。四种情况必须停：要改主文档结论、两个 active 决策冲突、要删文件、做完一条又引出新决策。

停下时要说清「为什么停」和「接下来有哪些选择」，不要只丢一句「需要你确认」。

## 八、结构与命名规则 {#structure v5}

项目根只有 `AGENTS.md`、`coperate/`、`<项目名>/`。下表路径**都相对 `coperate/`**。

| 目录 | 放什么 |
| --- | --- |
| `docs/` | 5 份主文档 |
| `decisions/` | 决策，只追加不修改 |
| `work/<日期>/` | 工作稿，不构成依据 |
| `assets/` | 长期素材 |
| `inbox/` | 人投递的素材，只有人能写 |
| `tools/` | 启动器与常设脚本（`kind: tool`），一次性脚本进 `work/<日期>/` |

`coperate/` 根只允许 `AGENTS.md`、`QUEUE.md`、`TASKS.md`、`build.py`、`BOARD.html`、`.scanignore`，加上上面六个目录。

项目自己的东西一律放 `<项目名>/` 下，校验器不看那个目录。

一律小写加连字符，不用驼峰——NAS 是 Linux 大小写敏感，写错了在 Windows 上测不出来。

命名前缀：`M-` 主文档 / `D-` 决策 / `P-` 待定 / `T-` 任务 / `W-` 工作稿。**编号永不复用**，新增取最大值 +1。

章节必须带锚点和版本：`## 一、标题 {#anchor v1}`。改内容必须涨版本。

`python tools/scan.py` 查六件事：target 断链、主文档漂移、孤儿产出、脚本身份块、脚本与文档版本一致、外来文件误放。

`python build.py` 生成看板。**不要手改 `BOARD.html`**，下次生成会覆盖。

## 九、每次开工前 {#daily v3}

顺序不能颠倒——先查再建，否则会把一个本来就断的台账复制进新页面。

1. `python tools/scan.py` —— 有「必须修」先修，不要带着断链继续加东西
2. `python build.py` —— 确认页面是最新的
3. 有积压的待确认先问，不要自己往下推
4. `inbox/` 非空就先分流，不要让它堆着
