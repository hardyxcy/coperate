## 六、这套骨架怎么复用 {#reuse v6}

本项目自身由规范项目的 `tools/scaffold.py` 生成，骨架源头在那边的 `templates/`。

要再派生一个新项目，**不要复制目录**，跑脚手架：

```
python <规范项目>/tools/scaffold.py ../新项目名
```

两条铁律：

- **工具无状态**：`build.py`、`tools/scan.py` 可被 `--sync-tools` 整体覆盖升级，本项目不要手改
- **文档有状态**：`docs/` 里是几个月的判断，**永远不要覆盖**，同步工具时一个字节都不碰

判断标准一句话：这个文件里有不在这份文件里的信息吗？有，就不能覆盖。
